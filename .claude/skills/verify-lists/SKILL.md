# Verify the Scanned and Marked lists

Read `../verify-app/common.md` first (setup, closing check, report).

1. **Scanned (typed searches).** Clean storage, open `#scanned summary` (title `S.lists.names.scanned` + " (N)"). Empty: count 0, empty-state text, Copy/Clear disabled. Search the first 11 `found` ISBNs from `test/fixtures/isbns.json`, with `invalid[0]` inserted as the 6th search: the count grows per real ISBN, not for the invalid one, ends at 11 (no limit of 10). Newest first; each row shows the name, two icon links and a ☆/★ button (no ISBN text). `localStorage['isbn-reader.scanned']` has the same order; a reload restores it.
   - Clicking a row name (Scanned or Marked) shows the card but does **not** reorder Scanned (a Marked book missing from Scanned is added on top); Back/Forward and a reload with `#isbn=…` don't reorder either. Only a new typed search or scan of a listed book moves it to the top, without a duplicate.
   - The row star marks the book (row ★, Marked gains it, the card's star flips if shown); ★ again unmarks.
   - Copy: `S.lists.copied(S.books(N))` (the plural is `S.plural`), `Title (ISBN)` per line (grant clipboard permissions). Clear: confirm `S.lists.clearScanned(S.books(N))` (`browser_click` + `browser_handle_dialog`: dismiss keeps, accept empties); Marked is untouched.
2. **Caps.** With 1000 entries in `isbn-reader.scanned` (valid-shaped, no real ISBN), searching a new ISBN still shows its card; `#list-warning` sits between `#result` and Scanned: `S.lists.listFull("scanned", 1000, S.lists.fullAdvice.scanned)`; the list stays at 1000 without the new ISBN. Searching an already listed ISBN moves it up with no warning; the warning also goes on the next listed-book search and when the list is cleared. With 1000 in `isbn-reader.marked`, the card's ☆ is refused (stays ☆) with `S.lists.listFull("marked", 1000, S.lists.fullAdvice.marked)`; unmarking one hides the warning.
3. **Corrupt storage.** Set `isbn-reader.scanned` to `[null,5,{"isbn":1}]`, then load `/` with no hash (a `#isbn=…` hash re-runs that search and adds a row): empty list, no console errors. Search `9780747532699`: the card renders and storage holds only valid entries (string `isbn` and `title`).
4. **Marked.** Clean storage, open `#marked summary` (`S.lists.names.marked` + " (N)"). Empty: count 0, empty-state text, Copy/Clear disabled. Search `9780141365466`, star it: ★ (`aria-pressed="true"`, tooltip `S.card.isMarked`, `aria-label` still `S.card.mark`), count 1, stored in `isbn-reader.marked`. Mark `9780747532699`: newest first.
   - Each entry: name, two `.icon-link`s (img `alt` "Ereadian"/"Goodreads", tooltip `S.card.linkTitle(isbn, site)`, hrefs `https://ereadian.com/search?q=<isbn>` / `https://www.goodreads.com/book/isbn/<isbn>`, `target="_blank"`, `rel="noopener noreferrer"`) and a ✕ (tooltip and `aria-label` `S.card.unmark`). No authors, no ISBN text. (Broken-icon box: abort `**/icons/*.png` with `page.route`, screenshot.)
   - Name click runs that search. ✕ flips a shown card's star back to ☆. Copy: `S.lists.copied(S.books(2))`. Clear: confirm `S.lists.clearMarked(S.books(2))` (dismiss keeps 2, accept empties and the card's button returns to ☆). A reload keeps what is marked. A legacy entry (`[{"isbn":"9780141365466","title":"Matilda","authors":["Roald Dahl"]}]`) shows "Matilda" and the links.
5. **Row layout** (360 px, 390 px, desktop; compare rects of `li`, `.open`, `.row-actions`; `scrollWidth` vs `clientWidth` of `.open`): each row is **one line**, name left (`.open`, single line, ellipsis when too long, `title` = full name), the two icon links and the star/✕ together at the right edge, vertically centred, no sideways page scroll. `ISBN 9789661092999` is shown in full at 360 and 390 px with a gap of about 8 px before the buttons; a short name keeps the same button positions; a very long name is truncated. **Underline:** the name buttons `.open` (Scanned and Marked) and the card's `.facts a` links have a solid 1 px underline (`text-decoration-line: underline`, `text-decoration-thickness` 1px, `text-decoration-skip-ink: none` so the letters don't interrupt it) with `text-underline-offset` not less than the value in `style.css` (`.3em`; the computed value is in px, so compare with 0.3 × the element's computed `font-size`). Row buttons' right edge equals the card star's right edge. (320 px may cut the standard name; with a 24 px root font the row may wrap with buttons under the name, still right-aligned.)
6. **Lists open themselves.** Clean load: `#scanned` and `#marked` collapsed. First search opens Scanned (not Marked), first star opens Marked. A list collapsed by hand stays collapsed on later additions. A load with non-empty lists shows them open.

Finish with the closing check from `common.md`.
